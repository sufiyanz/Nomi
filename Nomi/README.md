# Nomi - Language Learning App 🌸

A kawaii-style vocabulary learning app where you collect adorable stickers while learning new languages.

## Features

- **Sign in with Apple** - Simple, secure authentication
- **Multiple Languages** - Japanese, Korean, Spanish, French, German, Italian, Portuguese, Chinese
- **Location-based Learning** - Learn vocabulary organized by locations (Cafe, Restaurant, Store, etc.)
- **AI-Powered** - Words and sticker images generated by AI
- **Flashcard Revision** - Spaced repetition for effective learning
- **Kawaii Design** - Beautiful, soft aesthetic throughout

## Requirements

- iOS 26.0+
- Xcode 16.0+
- Swift 6.0

## Setup

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd Nomi
```

### 2. Configure API Keys

Create a `Secrets.plist` file in the `Nomi/` directory (this file is gitignored):

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>OPENAI_API_KEY</key>
    <string>your-openai-api-key-here</string>
</dict>
</plist>
```

Or set the environment variable:
```bash
export OPENAI_API_KEY="your-openai-api-key-here"
```

### 3. Open in Xcode

```bash
open Nomi.xcodeproj
```

### 4. Configure Signing

1. Select the Nomi target
2. Go to "Signing & Capabilities"
3. Select your development team
4. Update the bundle identifier if needed

### 5. Enable Sign in with Apple

1. In Xcode, go to the Nomi target
2. Select "Signing & Capabilities"
3. Add "Sign in with Apple" capability (should already be in entitlements)
4. Configure in Apple Developer Portal if needed

### 6. Build and Run

Select an iOS 26 simulator or device and run the project.

## Architecture

- **MVVM** with Swift Observation (`@Observable`)
- **SwiftData** for local persistence
- **SwiftUI** for all UI
- **Async/await** for networking

## AI Integration

The app uses OpenAI's APIs:
- **GPT-4o-mini** for vocabulary word generation
- **DALL-E 3** for kawaii sticker image generation
- **AVSpeechSynthesizer** for text-to-speech pronunciation
