# Wee App Documentation

Wee is a personal productivity app with Islamic features, combining daily planning with prayer time management.

## Project Overview

A SwiftUI-based iOS app that provides:
- Smart dashboard with time-aware greetings
- Prayer time management with location-based calculations
- Calendar and event management
- Task/chores tracking
- Modern glass morphism design

## Current Status

✅ **Completed:**
- Dashboard UI with intelligent welcome messages
- Day timeline view with current time indicator
- Design system with light/dark mode support
- App navigation structure
- Basic data models (Event, Item)

🚧 **In Progress:**
- Prayer times integration
- Calendar implementation

📋 **Planned:**
- Chores/tasks system
- Settings and preferences
- Notifications

## Quick Start

1. Open `Wee.xcodeproj` in Xcode
2. Select iOS Simulator target
3. Build and run
4. Navigate between tabs to explore current features
