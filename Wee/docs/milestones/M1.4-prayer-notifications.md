# M1.4 - Prayer Notifications

**Phase:** 1 - Prayer Times System  
**Priority:** HIGH  
**Estimated Time:** 2-3 days  
**Dependencies:** M1.1, M1.2, M1.3

## Objective
Implement a comprehensive notification system for prayer times, including local notifications, background scheduling, and integration with the Adhan audio system.

## Technical Requirements

### Notification Manager
```swift
class PrayerNotificationManager: ObservableObject {
    @Published var notificationSettings: PrayerNotificationSettings
    
    func scheduleNotifications(for prayerTimes: PrayerTimes)
    func cancelAllNotifications()
    func cancelNotification(for prayer: Prayer)
    func requestPermissions() async -> Bool
}

struct PrayerNotificationSettings {
    var enabled: Bool
    var fajrEnabled: Bool
    var dhuhrEnabled: Bool
    var asrEnabled: Bool
    var maghribEnabled: Bool
    var ishaEnabled: Bool
    var advanceMinutes: Int
    var soundEnabled: Bool
}
```

### Notification Types
- Prayer time arrival notifications
- Pre-prayer reminders (5, 10, 15 minutes before)
- Custom notification sounds
- Rich notifications with prayer info

## Privacy & Permissions

### Permission Flow
1. **Context:** Explain why notifications are needed
2. **Timing:** Request permission when user enables notifications
3. **Graceful Fallback:** App works without notifications
4. **Settings Access:** Easy way to change permissions

### Permission States
- **Authorized:** Full notification functionality
- **Denied:** Show settings guidance
- **Provisional:** iOS 12+ quiet notifications
- **Not Determined:** Show permission request
