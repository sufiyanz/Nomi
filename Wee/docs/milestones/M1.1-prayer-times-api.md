# M1.1 - Prayer Times API Integration

**Phase:** 1 - Prayer Times System  
**Priority:** HIGH  
**Estimated Time:** 3-5 days  
**Dependencies:** None

## Objective
Integrate a reliable Islamic prayer times API to fetch accurate prayer times based on user location, replacing the hardcoded prayer times currently displayed in the dashboard.

## Technical Requirements

### API Selection
- **Recommended:** Aladhan API (https://aladhan.com/prayer-times-api)
- **Alternative:** Islamic Network API
- **Backup:** Prayer Times API by MuslimSalat

### Data Model Updates
```swift
// New PrayerTimes model
@Model
final class PrayerTimes {
    var date: Date
    var fajr: Date
    var sunrise: Date
    var dhuhr: Date
    var asr: Date
    var maghrib: Date
    var isha: Date
    var location: String
    var method: Int // Calculation method
}
```

### Service Layer
```swift
// Prayer times service
class PrayerTimesService {
    func fetchPrayerTimes(latitude: Double, longitude: Double, date: Date) async throws -> PrayerTimes
    func getCurrentPrayer(for prayerTimes: PrayerTimes, at time: Date) -> Prayer
    func getNextPrayer(for prayerTimes: PrayerTimes, at time: Date) -> Prayer
}
```

## API Documentation

### Aladhan API Endpoints
```
GET https://api.aladhan.com/v1/timings/{date}
Parameters:
- latitude: User latitude
- longitude: User longitude  
- method: Calculation method (1-15)
- tune: Time adjustments
```

### Response Format
```json
{
  "data": {
    "timings": {
      "Fajr": "05:30",
      "Sunrise": "07:00",
      "Dhuhr": "12:15",
      "Asr": "15:30",
      "Maghrib": "18:00",
      "Isha": "19:30"
    },
    "date": {
      "readable": "21 Sep 2025",
      "gregorian": {...},
      "hijri": {...}
    }
  }
}
```

## Edge Cases to Handle

1. **Extreme Latitudes:** Areas where prayer times may not occur
2. **Daylight Saving:** Time zone changes
3. **Date Transitions:** Prayer times crossing midnight
4. **API Rate Limits:** Handling quota exceeded errors
5. **Invalid Locations:** Coordinates in ocean or invalid areas
