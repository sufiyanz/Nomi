## Event Validation

### Validation Rules
```swift
struct EventValidator {
    static func validate(_ eventData: EventFormData) -> [ValidationError] {
        var errors: [ValidationError] = []
        
        if eventData.title.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty {
            errors.append(.emptyTitle)
        }
        
        if eventData.endDate < eventData.startDate {
            errors.append(.endBeforeStart)
        }
        
        // Additional validation rules...
        return errors
    }
}

enum ValidationError: LocalizedError {
    case emptyTitle
    case endBeforeStart
    case titleTooLong
    case pastDate
    
    var errorDescription: String? {
        switch self {
        case .emptyTitle: return "Event title cannot be empty"
        case .endBeforeStart: return "End time must be after start time"
        case .titleTooLong: return "Event title is too long"
        case .pastDate: return "Cannot create events in the past"
        }
    }
}
```

## Error Handling

### Common Error Scenarios
1. **Network Issues:** When syncing with external calendars
2. **Data Conflicts:** Concurrent modifications
3. **Validation Errors:** Invalid user input
4. **Storage Errors:** SwiftData operation failures
5. **Permission Issues:** Calendar access denied

### Error Recovery
```swift
func handleEventError(_ error: EventError) {
    switch error {
    case .validationFailed(let messages):
        showValidationErrors(messages)
    case .saveFailure:
        showRetryOption()
    case .networkUnavailable:
        enableOfflineMode()
    }
}
```
